# Project Rules & Preferences

## 1. Version Control (Git) Policy
- **Strict User-Directed Commits & Pushes:** NEVER commit or push code automatically or proactively.
- Only create git commits or push to remote repositories when the user explicitly commands or asks to do so.

## 2. Analysis & Long Output Policy (Markdown Files Preferred)
- **File Output over Terminal/Chat Dumps:** Whenever an analysis, report, or explanation:
  - Includes tables, charts, or diagrams (such as Mermaid diagrams), OR
  - Exceeds 20 lines of structured analysis
- Do NOT output it as an overly long terminal/chat message. Instead:
  - Write it directly into a designated Markdown (`.md`) file on disk or project workspace.
  - In chat, provide a concise summary (under 20 lines) highlighting key points and provide a direct clickable link to the `.md` file.
